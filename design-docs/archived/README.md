# Archived design documents

These record what was believed at the time. They are kept for the reasoning,
not as a description of the tool. `design-docs/` at the top level is the
current state.

- `initial-design.md` — the original single-PNG temporal-projection proposal.
  Superseded once the projection was built and measured against a known
  scenario: one scene cut saturates the whole image, and a fade never appears
  in it at all. The projection survives as one output among several rather
  than as the product. See `../decisions.md` entries D1-D4.
